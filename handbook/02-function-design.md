## 剪贴板关键规则

- 每秒比较 `NSPasteboard.general.changeCount`；敏感、临时和自动生成标记在读取内容前排除。
- 可暂停采集或排除来源应用；现有历史仍可复制，恢复采集不会补录暂停或排除期间的当前剪贴板。来源由采样时的前台应用识别，应用间异步写入可能归到当时的前台应用。
- 支持文本与图片。文本完整保存；图片保存关闭时不读取图片数据，开启时保留原始 PNG/TIFF（兼容旧 JPEG）并另建最长边 80 像素的 JPEG 缩略图。
- 先检查过滤词和重复内容再入库。搜索同时匹配原文和名称，为 Unicode 大小写不敏感的普通包含匹配，不支持模糊或正则语义。
- 固定项可右键重命名，名称去除首尾空白、最多 200 字符且单行；空名称恢复默认展示。取消固定保留名称，再次固定可继续编辑。名称只改变展示与搜索，不改变原内容。
- 列表按固定状态、创建时间和 id 稳定排序，每页 200 条摘要，以游标追加；历史变更后重载，后台查询必须防止旧请求覆盖新结果。加载期间的方向键和 Enter 按输入顺序执行。
- 点击或 Enter 只把内容写回剪贴板，不模拟粘贴。图片必须先读取并验证，成功后才能清空/改写剪贴板；文本以纯文本回写。
- 历史清理支持仅删非固定项或清除全部。启动、每小时、唤醒及设置变更时清理过期项；永久保留仍清理孤儿图片。
- 原图和缩略图合计 500MB 后，从最旧的非固定图片开始清理；固定项永不因容量阈值删除。
- 自定义保留天数只接受 1–365 的整数；无效输入不改偏好、不触发清理。
- 改变保留天数会先统计将删除的非固定项；数量大于零时确认数量、不可恢复和固定项保护，取消不改偏好。
- 删除返回明确的提交状态。数据库已删除但文件/WAL 清理失败时刷新列表、说明仍需清理并提供重试；成功才表示本地库和 WAL 清理完成，不涵盖系统快照或人工备份。
- 可选全局打开快捷键默认关闭；注册冲突时保留原配置并提示。

## 监控、电量与系统能力

- `MonitorMode` 选择 CPU、内存或两者较高值；`DisplayMode` 选择动画或动画加数值。Compact Values 使用独立双行 C/M 渲染路径。
- M 为物理内存占用率：`max(0, active + inactive + wired + compressor - purgeable - external) / physicalMemory`，限制在 0–100%。计入应用、系统和压缩内存，排除可回收文件缓存；swap 属于磁盘，不再强制抬高数值。这是占用口径，不是 macOS 内存压力指标。
- 电量项只显示窄数字。使用电池且电量正常时为蓝色，≤20% 橙色、≤10% 红色；接电/充电优先显示粉色底纹与描边。充电字段缺失时显示未知，不以接电状态推断充电。
- 电量项左键循环 CaffeineMode，右键显示电量、电源、充电状态、低电量模式和系统设置入口。
- Finder 无窗口时目标回退桌面；Apple Events 权限失败时说明原因并允许手选目录。创建使用排他写入，避免并发覆盖。

## 通用边界

语言切换同时刷新菜单与面板。系统权限、数据库或文件操作失败必须给出可恢复反馈，且不阻塞无关模块。所有用户数据留在本机，只有主动检查更新会请求 GitHub Releases 页面。
