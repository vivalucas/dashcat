# UI 与交互约定

> 适用状态：启用。DashCat 使用 AppKit 原生菜单、状态项和非激活面板，不采用网页组件体系。

## 设计方向与入口

界面追求菜单栏工具的轻量、克制和低占位：高频动作一步到达，低频设置放在右键菜单，反馈简短而可恢复。主界面不是传统窗口，也不应为新增设置默认创建窗口。

| 内容 | 唯一维护位置 / 参考 |
| --- | --- |
| 主状态项、菜单、颜色和本地化 | `DashCat/AppDelegate.swift` |
| 剪贴板面板、列表、搜索、空状态与键盘交互 | `DashCat/ClipboardPanel.swift` |
| 图片缩略图 | `DashCat/ClipboardManager.swift` 生成，面板异步加载 |
| 代表性流程 | 左键剪贴板面板；右键设置菜单 |

## 当前规则

- 主状态项左键打开/关闭剪贴板面板，右键打开设置；菜单关闭后恢复左键行为。
- 面板锚定状态栏按钮，保持非激活浮窗体验；搜索无结果与完全无历史使用不同空状态文案。
- 搜索框保留输入法标记文本；方向键改变选择但不触发复制，Enter 才确认。后台结果回来前检查请求是否仍有效。
- 缩略图不在主线程同步读盘；复制、清除、权限及更新检查均提供成功、失败或进行中反馈。
- 菜单按 Monitor、Battery、Clipboard Settings、系统工具和 Help & Updates 等任务分组，避免过深层级和工程术语。
- 电量显示不增加百分号；状态通过文字颜色、底纹与描边表达，仍需 tooltip/菜单文字补足含义。
- 支持 11 种语言；新增用户可见文案必须补齐所有现有语言，不以英文静默兜底掩盖漏译。

## 验收

UI 改动至少检查左右键入口、面板定位、键盘与输入法、空/错/加载/禁用状态、多屏边界和菜单状态同步。可运行时查看真实界面；构建通过不能替代视觉与系统交互验收。
