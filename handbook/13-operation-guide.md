# 使用与管理指南

> 适用状态：启用；读者为 DashCat 用户。完整产品介绍与安装说明以根 [README](../README.md) 为准。

## 日常入口

- 左键猫咪：打开简洁剪贴板列表；输入关键词搜索原内容或名称，方向键选择，Enter 或单击复制完整原内容。右键可固定、预览，固定后可重命名；名称留空或“清除名称”恢复默认显示，尾部图钉是状态标记。
- 右键猫咪：配置监控、剪贴板保存与清理、电量项、防休眠、滚轮反转、Finder 新建文件、语言、开机启动和更新检查。
- 左键电量数字：循环切换防休眠状态；右键查看电量详情。
- 右键猫咪 → 剪贴板设置：可暂停/恢复采集，或排除指定应用。暂停后历史仍可复制，恢复不会补录跳过的内容；应用排除按采样时的前台应用判断。
- 菜单栏 M 显示内存占用率，计入应用、系统及压缩内存，排除可回收文件缓存；可悬停查看指标含义及当前采集/休眠状态。

## 权限与恢复

- 滚轮反转无效时，在系统设置的“隐私与安全性 → 辅助功能”允许 DashCat；拒绝不会影响其他功能。
- Finder 新建文件首次使用可能请求自动化权限。拒绝或读取目录失败时可手动选择文件夹；该功能不会向 Finder 注入右键菜单。
- 预构建版本若被 Gatekeeper 拦截，优先尝试 Finder 右键“打开”；根 README 记录了移除隔离标记的方法。自行用 Xcode 和个人账号签名可避免这一安装路径。

## 数据与清理

历史位于 `~/Library/Application Support/DashCat/`。清除历史前会选择仅清除非固定项或清除全部；后者会同时删除对应图片。若需人工备份，先退出 DashCat，再整体复制该目录。应用目前不提供已验证的一键恢复或跨设备同步。

改变保留天数若会删除记录，先确认数量，固定项保留；取消则维持原设置。提示“记录已更新，清理仍需完成”时，列表已反映数据库结果，可在面板或剪贴板设置中重试清理。图片缺失或损坏时复制失败，原剪贴板内容保留。清理范围为当前本地数据库、WAL 和图片文件，不会清除外部备份。

完成检查：菜单栏出现猫咪；左键可打开面板；右键菜单状态正确。涉及滚轮、Finder、登录项或电量的功能应在实际设备和相应权限状态下单独确认。
