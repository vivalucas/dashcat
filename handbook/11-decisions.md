# 决策与经验

仅保留仍约束当前项目的重要取舍及防复发经验。

## D-006：剪贴板历史完整性优先

- 状态与日期：当前有效；2026-09-12。
- 选择与依据：完整保存纯文本与原始 PNG/TIFF，缩略图独立生成；固定图片不因容量阈值删除；列表后台分页加载。
- 代价与边界：存储可能增大；旧版已丢失内容不可恢复；不扩展为 OCR、富文本或全文检索。
- 防复发：运行剪贴板回归，保留旧 JPEG/绝对路径兼容、查询完整成功后才清孤儿和固定项保护。
- 重评条件：存储模型、同步需求或数据规模发生显著变化。

## D-005：Finder 新建文件只走 DashCat 菜单

- 状态与日期：当前有效；2026-05。
- 选择与依据：AppleScript 读取 Finder 目录，权限失败时允许手选目录；不建设 Finder Sync Extension。
- 代价与边界：入口不出现在 Finder 空白处右键菜单，并受 Apple Events 权限约束。
- 防复发：保持排他创建、重名递增和权限失败恢复路径。

## D-004：极简电量项独立显示

- 状态与日期：当前有效；2026-05。
- 选择与依据：独立 `NSStatusItem` 只显示窄数字，避免挤占猫咪主状态项。
- 代价与边界：只提供轻量详情，不复制系统电池管理功能；状态语义需由颜色、tooltip 与右键菜单共同表达。

## D-003：搜索采用 Unicode 包含匹配

- 状态与日期：当前有效；2026-09-12 更新实现。
- 选择与依据：用户输入关键词即可命中，语义简单；使用 Foundation 大小写不敏感比较，通配符按字面处理。
- 代价与边界：不支持模糊、正则和全文索引；数据规模增长后再评估索引方案。

## D-002：SQLite 与图片文件共同持久化

- 状态与日期：当前有效；2026-05。
- 选择与依据：单机历史的排序、分页、清理比 JSON 更直接，且无需 Core Data/SwiftData 抽象。
- 代价与边界：数据库记录和文件生命周期必须显式保持一致；所有访问走串行队列。

## D-001：纯 AppKit、菜单即配置、零第三方依赖

- 状态与日期：当前有效；项目初始设计。
- 选择与依据：菜单栏工具强调低占用和短操作路径；现有规模不需要 SwiftUI 混合、独立设置窗口或复杂分层。
- 代价与边界：`AppDelegate.swift` 较大；新增能力先判断是否仍适合菜单和单进程模型。
- 重评条件：模块规模明显阻碍维护、系统 API 不再满足需求，或产品需要复杂设置/多窗口体验。

## 通用经验

- 数据库查询失败不能等价为空集合，否则孤儿清理可能误删文件。
- 外部内容必须先成功读取/验证，再清空用户剪贴板。
- 系统字段缺失保留“未知”，不要用相关但不同的状态推断。
- 权限能力失败应局部降级并提供恢复方式，不影响其他菜单栏功能。
